# Portfolio

Dark, terminal-styled developer portfolio built from the reference reel in
`assets-source/reference-video.mp4`.

**Stack:** Vite · React 19 · TypeScript · Tailwind v4 · GSAP ScrollTrigger · Lenis

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
```

## All content is dummy data

Every personal detail lives in `src/data/`. Nothing is hardcoded in components.

| File | Contents |
|---|---|
| `profile.ts` | Name, role, bio, email, socials, hero headline phases |
| `expertise.ts` | The four `// ROOT 0n` capability cards |
| `stack.ts` | Marquee chips (two rows, opposite directions) |
| `timeline.ts` | `// ENGINEERING ROADMAP` milestones |
| `projects.ts` | Carousel cards |
| `certifications.ts` | Credential grid |

Replace those seven files and the site is yours.

## The hero frame-scrub

The signature effect: scrolling scrubs a portrait turnaround while the headline
swaps. Implementation:

- `public/hero/frame_000…047` — the turnaround sequence
- `src/hooks/useFrameSequence.ts` — preloads all frames; the boot loader is
  gated on this so the scrub never stutters on a cold frame
- `src/sections/Hero.tsx` — ScrollTrigger pins the section over 300vh and maps
  scroll progress to a frame index, drawing to `<canvas>` with cover-fit math

Current frames are **procedural SVG placeholders** generated by
`scripts/gen-placeholder-frames.mjs`. To swap in real photos:

1. Export 48 frames as WebP, ~1200×1600, 40–60KB each
2. Name them `frame_000.webp` … `frame_047.webp` in `public/hero/`
3. Change the extension in `heroFrameSrc()` in `useFrameSequence.ts`
4. Delete the placeholder script and the `.svg` frames

Reduced-motion and small screens fall back to a single static frame, no pin.
